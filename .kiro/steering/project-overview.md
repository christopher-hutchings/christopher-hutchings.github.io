# Project Overview

## About
This is the website for **Rebalance Amatsu with Hannah** — an Amatsu therapy practice run by Hannah Boot in Portishead, near Bristol. The site is hosted on GitHub Pages with the custom domain `rebalanceamatsu.co.uk`.

## Tech Stack
- **HTML5** — static multi-page site (no build step, no framework)
- **Tailwind CSS** — loaded via CDN (`https://cdn.tailwindcss.com`)
- **Custom CSS** — `styles.css` for brand colours, background effects, and utility classes
- **No JavaScript framework** — vanilla JS for the mobile menu toggle only
- **Hosting** — GitHub Pages with CNAME pointing to `rebalanceamatsu.co.uk`
- **Forms** — contact form uses FormSubmit.co for email delivery
- **Booking** — external link to Fresha for appointment scheduling

## Pages
| File | Purpose |
|------|---------|
| `index.html` | Homepage with hero, image gallery, CTA |
| `about.html` | Hannah's background and qualifications |
| `amatsu.html` | Explanation of Amatsu therapy |
